🍎 Fruit Classification

Healthy vs Rotten Fruit Classification Using Deep Learning

Project Overview

This project focuses on developing a Deep Learning model to classify fruits into two categories: Healthy and Rotten.

The model uses Transfer Learning with the ResNet18 architecture to recognize visual patterns and classify fruit images.

Project Objective

The main objective is to build an image classification system that can automatically distinguish healthy fruits from rotten fruits based on their visual characteristics.

Dataset

The dataset consists of fruit images organized into two categories:

  • Healthy Fruits
  • Rotten Fruits

Images are resized to 224 × 224 pixels before being passed to the model.

Technologies & Tools

Python PyTorch ResNet18 Transfer Learning NumPy Scikit-learn Streamlit

Methodology

  1. Collecting and organizing fruit images.
  2. Preprocessing and resizing images.
  3. Splitting the dataset into training, validation, and testing sets.
  4. Loading the pretrained ResNet18 model.
  5. Training and evaluating the model.
  6. Saving the trained model for future predictions.
  7. Developing a user interface for image prediction.

Model Architecture

ResNet18 is used as the backbone architecture for image classification.

Transfer Learning allows the model to use previously learned visual features and adapt them to the fruit classification task.

Results

The trained model can predict whether an input fruit image belongs to the Healthy or Rotten category.
